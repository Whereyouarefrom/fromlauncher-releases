# fromlauncher-releases
FL — FromLAUNCHER

Лаунчер для Ukraine GTA, який реально робить свою роботу — а не просто красиво лагає на екрані завантаження. Жодних танців із бубном навколо шляхів до гри, ручної заміни модів та мук із OBS — усе в одному місці, в один клік.

🔥 Що всередині:

🗂 Каталог модів та збірок — завантажив, застосував, погнав. Без танців із архівами та WinRAR-шаманства.

🎯 Автовалідація шляхів — лаунчер сам бачить, якщо ти підсунув не ту папку, і не дасть тобі сидіти в подиві, чому гра не запускається.

📸 Вбудований скриншотер — Caps Lock (та інші клавіші) — і готово, жодних PrtScr тощо!

🖥 HUD-оверлей — FPS та годинник прямо в грі.

⚡ Force Close — гра зависла? Один клік — та вона закрита.

🌐 4 мови — RU / UA / EN / PL, бо ком'юніті Ukraine GTA велике.

🔄 Автооновлення — лаунчер, оверлей та інсталятор оновлюються самі, без твоєї участі.

🛡 OBS / ShadowPlay / Bandicam автодефект — записуй контент без півгодинного налаштування та інших гемороїв.

💻 Для кого:

Для тих, хто хоче запускати моди та записувати фрапси, а не розбиратися у файловій системі гри, наче сапер на мінному полі.
